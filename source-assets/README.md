# Source media

This directory keeps original, full-resolution team photography outside the public deployment tree. The website uses selected WebP derivatives in `public/images/team/`, generated by:

```bash
node scripts/optimize_team_photos.mjs
```

Keeping the originals here preserves future cropping and print options without adding more than 30 MB of raw photography to every web deployment.

`legacy-brand/` preserves retired logo and banner files for archival reference. They are deliberately outside `public/` so the redesigned site cannot accidentally serve the old identity.
